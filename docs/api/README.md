# Lazy Sleeper API 0.1.1 — endpoint reference

Generated by `lazy api export` from the live FastAPI app; the authoritative
machine-readable contract is `openapi.json` next to this file (also served at
`/openapi.json`, interactive at `/docs`). All responses are JSON unless marked HTML.
No auth (the draft-night host is reached over Tailscale). Times are ISO-8601 UTC.
Client workflows, untyped response shapes and field semantics: `GUIDE.md`.

## Endpoints

| Method | Path | Purpose | Query / body | Returns |
|---|---|---|---|---|
| GET | `/health` | Liveness: `{"status": "ok"}`. | — | object |
| GET | `/snapshots` | Most recent raw snapshots (id, source, kind, season, week, pulled_at, record_count, valid, byte_size) — the data-freshness view. | `limit?` | array |
| GET | `/ensemble/weights` | Weights in force per position, plus the fitted and override rows and the config flags. | `horizon?` | object |
| PUT | `/ensemble/overrides` | Set the manual (λ) override for one position. Does not flip use_overrides by itself. | body `OverrideBody` | object |
| DELETE | `/ensemble/overrides` | Remove the manual override for one position, or all positions when omitted. | `horizon?`, `position?` | object |
| PUT | `/ensemble/config` | Flip use_overrides and/or pin a fitted version (`latest: true` clears the pin). | body `ConfigBody` | object |
| GET | `/board/config` | Tier/cliff/flag thresholds in force (defaults seeded by migrations 0006/0007). | — | object |
| PUT | `/board/config` | Adjust any subset of the tier/cliff/flag thresholds (draft-day dial). | body `BoardConfigBody` | object |
| GET | `/board` | The latest persisted board: ranked rows with points, VORP, tier/cliff, ADP delta, disagreement spread/flag and injury status. `position` filters; `rank` stays overall. | `season?`, `provider?`, `position?`, `limit?` | object |
| GET | `/board.html` | Self-contained HTML view of the latest board — the draft-night fallback. | `season?`, `provider?` | HTML |
| POST | `/board/regen` | Rebuild the board from core.* under the current config and persist it — on-demand regen, so a `PUT /board/config` change shows up without waiting for the daily job. | body `RegenBody` | object |
| POST | `/draft/{draft_id}/start` | Pre-draft load (board + ADP + player lookup, once) and start polling Sleeper for this draft on a background thread. Idempotent while the runner is alive. Do this *before* the draft room opens — the board build takes seconds, the recompute per pick ~50 ms. | body `DraftStartBody?` | `DraftStartOut` |
| POST | `/draft/{draft_id}/stop` | Stop polling this draft (`{draft_id, running}`); 404 if it isn't running. | — | object |
| GET | `/draft/{draft_id}/state` | The decision surface from the latest recompute: clock, my roster + needs, available players by pick_score with tier/cliff/run/survival. `recompute.stale`/`error` flag a failed recompute (rows are then the previous good ones). 404 until `POST /draft/{id}/start`. | `position?`, `limit?` | `DraftStateOut` |
| GET | `/draft/{draft_id}/state.html` | The draft-night fallback (LS-37): a self-contained page that polls `/draft/{id}/state` every `refresh` seconds and offers the start button when the runner isn't up. Phone- and second-monitor-readable; no build step. | `season?`, `limit?`, `refresh?`, `interval?` | HTML |
| GET | `/board/config.html` | Tuning page: every `board_config` dial as a form → `PUT /board/config`, then apply to the running draft (`POST /draft/{id}/config`) — signal dials instantly, board-time dials via a restart. Linked from the draft page so no CLI is needed on draft night. | `draft_id?` | HTML |
| POST | `/draft/{draft_id}/config` | Push the stored `board_config` into the running draft. Without `restart` only the draft-time dials (survival, runs, need bonus, late_rounds) change — instant recompute. With it the runner is stopped and started again (board rebuild, a few seconds). | `restart?` | object |
| GET | `/draft.html` | `/draft/{id}/state.html` for the configured `sleeper_draft_id` — the bookmark. | `season?`, `limit?`, `refresh?`, `interval?` | HTML |
| GET | `/draft` | Drafts known to this API process: `[{draft_id, running, season}]`. | — | array |
